# NightPDF Agent Notes

- Build a native iPadOS app using Swift, SwiftUI, PDFKit, and PDFView.
- Keep the project dependency-free and offline.
- Do not add analytics, ads, backend calls, secrets, certificates, provisioning profiles, Apple IDs, or passwords.
- Keep PDF transformations visual only. Never rewrite or mutate the imported PDF for night mode.
- Prefer small model, service, and view files over concentrating logic in one SwiftUI view.
- GitHub Actions must build and test on macOS without requiring signing secrets.
